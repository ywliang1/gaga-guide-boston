# 2027 Gaga Guide Boston

Gaga's personal ranking of 140 Greater Boston restaurants in eight tiers, from T0 (Best of Boston) to T5 (Terrible cooking, please avoid).

The site is a single static page: `index.html` plus the food photos in `img/`. It needs no build step, so GitHub Pages can serve it as is.

Photos come from the restaurants' public listings and reviews online and belong to their photographers. Sources are listed at the bottom of the page.
